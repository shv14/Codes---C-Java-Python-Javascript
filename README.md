# 🚀 Codes — C, Java, Python, JavaScript

Welcome!  
This repository is a collection of various code snippets, problem-solving scripts, and small programs written in **C**, **Java**, **Python**, and **JavaScript** — all stored in a single place.

## 📌 About

The purpose of this repo is to:

- Practice coding in multiple languages
- Experiment with different logic and algorithms
- Keep track of useful examples for learning and reference

## 🗂️ What's Inside?

You’ll find:

- 🔢 Coding exercises
- 🧠 Algorithm implementations (like sorting, searching, recursion, etc.)
- 💻 Small scripts and logic-building examples
- 🎯 Language-specific syntax demos

All code files are located in the root of this repo and are named based on their function or problem being solved.

## 🧾 File Naming Convention

Each file is usually named according to its functionality or the concept it covers.  
Examples:

- `fibonacci.py` — Python code for Fibonacci series
- `BubbleSort.java` — Java implementation of Bubble Sort
- `factorial.c` — C code to calculate factorial
- `calculator.js` — Simple JavaScript calculator logic

- Pick a file you’re interested in
- Open and study/run the code in your preferred environment
